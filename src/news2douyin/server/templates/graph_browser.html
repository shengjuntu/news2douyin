如何启动 Browser

配套 Compose 在同一 FalkorDB 容器上提供 Browser 端口：本机默认 13000，对应容器 3000。更新配置后在源码包根目录执行：

docker compose -f deploy/falkordb.compose.yaml up -d

默认仅本机可访问。需要远程访问时，按部署说明设置 Browser 监听地址并配置访问控制。网页地址与数据库的 redis:// 连接地址分别配置。
