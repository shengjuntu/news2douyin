研究助手设置

返回深入研究

一键 Docker 自主研究需要 RunDesk 0.47.1 或更新版本。首次选好镜像并完成模型认证，之后开始研究时会自动启动对应环境。

执行环境

点击“连接并配置环境”后应用于新闻 Docker 实例及当前已启用 MCP。可修改挂载的项目文件；系统目录仍受 Docker 只读限制。仅保存设置不会改变运行权限。

使用在 RunDesk 主机上已构建的镜像。首次连接可以绑定；后续更换镜像在 RunDesk 中更新环境。

研究外部搜索：Codex → Exa

news2douyin 负责本地新闻库、检索预算、线索和证据保存；外部搜索统一由 RunDesk 中的 Codex 调用 Exa。不会调用新闻采集的 WorldNewsAPI，也不需要在这里填写第二套搜索账号。

先在 RunDesk 准备镜像，再点击连接并配置环境。升级后请停止旧轮次，在原课题开始新一轮；已有证据和报告保留。

高级：服务访问地址

默认从当前访问地址识别；只有反向代理或跨机器无法访问时才需要覆盖。

填写容器可访问的 news2douyin 地址。同机 localhost 自动映射到宿主；服务仍需监听容器能连接的地址。跨机器请填实际可达地址。

研究策略

策略修改用于新建课题；已有课题保留创建时的策略版本。停用策略不删除历史研究。
