# 专题删除与恢复

在专题标题旁点击“删除专题”，确认后移入回收站：停止此专题的持续跟踪，从正常列表和关联菜单移除。页面侧栏的“已删除专题”可以恢复，也可以通过 `/focus?trash=1` 直接展开。

删除保留原始报道、事件、已建立的内容任务和研究成果。未提交的补查取消；已经交给研究系统的独立任务仍可在运行管理中查看。这不是物理清库，也不承诺回收磁盘空间。专题名称为恢复保留；再建同名专题时会提示先恢复或换名。

恢复保持暂停，不自动恢复模型调用或自动研究。此前已接受的材料和研究记录可继续查看；再次编辑关注范围或启用跟踪时，后台按新版本重新检查材料。

## 并发与图一致性

删除与恢复各自使用一个事务，校验当前版本并写入独立 `FocusTrash` 生命周期记录，升级不改写旧 Watch 大表。待处理历史扫描暂停，未完成的相关性候选过期，未提交复查取消。在途模型结果提交前仍检查启用状态和版本，无法复活已删除专题。研究的本地提交使用短暂生命周期租约；正在提交时删除会提示稍后重试，成功删除后不会再开始新的专题研究提交。

图投影通过原有持久队列异步设置该专题的全局 Focus 和专题图 Question 根节点为 `archived=true`，全局 Focus 同时停用；不删除共享 Event、Article 或证据关系。正常专题接口隐藏回收站项目，原生图浏览器可保留带归档标志的历史。专题已归档时不继续物化材料或执行该专题图的自动清理。恢复时清除归档标志，按原身份推进增量投影；保留原有图收据。

恢复时仅保留当次删除前有效的归集版本作为只读基线，不复制或批量重写历史候选。任何后续范围编辑或启用递增版本都会使此基线失效，避免旧结论被当作新范围的判断。

恢复请求必须带回收站当前删除版本。旧页面的恢复请求遇到后来再次删除时返回冲突，不会恢复新一轮删除；同代成功恢复后的重复请求只返回现状，不重新启动或暂停跟踪。
