# 0.30.0：让事件卡片显示报道内容

此前全球事件线索把“主体＋CAMEO类别＋对象”作为标题，例如`ZUNI · 交战 · MOROCCO`。它能显示编码关系，却没有说明来源报道讲了什么，不能支持实际选题。本版补上报道内容链路，原始事件编码保留为辅助信息。

## 使用上的变化

- 卡片主标题优先显示真实来源报道标题，下面显示来源摘要或可读正文摘录、来源域名及语种；国家、类别、主体和日期退为辅助信息。
- 先从本站已保存的报道匹配内容；没有时由独立后台安全读取来源页面。列表、详情及刷新接口只读SQL，不在页面请求中抓网页、等待模型或打开原始接收库。
- 缺内容时显示“报道内容待补充”；只有标题时保留真实标题并标记摘要待补。可点击单条或“补充本页报道”排队，取不到的来源保留明确错误，不用编码或URL猜新闻。
- 中文译读翻译当前可见的报道标题和摘要；翻译输入冻结保存，不只是翻译人物、国家和行为标签。没有模型配置时原文仍可阅读。
- 形成选题时默认采用真实标题，并冻结当时的报道摘要、来源与哈希；仍先补原文和核查，再进入研究与创作。

一篇报道可能关联多个GDELT编码事件，因此界面明确称为“相关报道”。标题、网页描述和摘录不等于本条事件已经核实，也不是LLM生成的事件总结。

## 升级与运行

这是完整包，包含0.29.1的索引迁移、故障隔离和接收诊断。保留原数据库地址、存储目录、`.env`与图命名空间，按原方式停应用并备份后更新源码或安装wheel：

```bash
python -m pip install --upgrade --no-deps ./release-0.30.0/news2douyin-0.30.0-py3-none-any.whl
python -c "import importlib.metadata,news2douyin;print(importlib.metadata.version('news2douyin'));print(news2douyin.__file__)"
```

Editable部署须更新完整源码，再使用实际服务Python运行`python -m pip install -e . --no-deps --no-build-isolation`。项目依赖集没有新增要求；保留`NEWS2DOUYIN_GKG_AUTO_EVENTS=0`。

启动自动补建`sourcepreview`与`sourcepreviewjob`两张小表。默认开启`NEWS2DOUYIN_SOURCE_CONTENT_ENABLED=1`，后台有界补充最近事件的来源，页面明确请求优先。设置0只停止该补材后台，不影响GDELT全量原档接收和已保存内容的显示。初次打开页面不会自动提交整页抓取请求。

补材不创建本地事实Event，不修改原始文章版本，不触发LLM抽取或自动深度研究。缓存只存标题、有限摘录和来源元数据，不复制完整网页。详见[内容契约](EVENT-CONTENT.md)。

## 边界

有些来源会返回403、验证码、登录页、付费墙或失效链接；本版不会绕过访问限制。PDF留在研究读取阶段，不为事件卡重复下载。没有取得的内容保持未知。

传输沿用公网地址校验、逐跳DNS检查、固定连接IP和HTTPS域名验证。预览另加35秒整体预算及512KiB解码响应上限；旧研究读取默认行为保持兼容。

验证使用合成报道、受控HTTP/TLS、临时PostgreSQL/SQLite及真实浏览器。没有把截图中的两个编码推测成真实新闻，也没有在用户服务器部署或调用真实LLM。
