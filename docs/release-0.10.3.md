# 0.10.3：首次运行检查

原定业务主线已实现，但首次部署时新闻账户、模型地址、定时计划和编码环境分散在不同位置。本版新增 `/setup`，用于发现配置缺项并引导实际试跑。

## 入口与检查内容

页脚和运行管理均有“首次运行检查”。每日选题没有已启用策略时，也提供直接入口。

| 项目 | 检查内容 | 仍需实际验证 |
|---|---|---|
| 新闻策略 | 演示/真实新闻、启停、密钥变量是否有值、主动检索是否填写查询词 | 新闻源权限、限额、历史范围、抓取覆盖率；到策略页试跑 |
| 自动采集 | 启用计划、关联策略是否存在/启用/具备配置、Cron 与时区、下一次计划时间 | 当前调度器运行和服务驻留；计划本身有下一次时间不代表已经执行 |
| 模型配置 | 当前模型名、服务主机、鉴权是否设置、哪些参数仍使用默认值 | 主动检查列表，再生成一条 AI 初稿 |
| 视频环境 | 复用制作页的 FFmpeg、H.264/AAC、FFprobe、Pillow、中文字体与配音依赖检查 | 实际合成、编码及成片效果；可选配音依赖缺失不妨碍上传配音 |
| 服务与存储 | 数据库读取、运行目录存在和权限预检、当前执行器/调度器、当日日期与默认时区 | 实际写入、磁盘空间、多实例和长期运行 |

不要求所有可选项都齐全：基础摘录稿无需模型，手动采集无需定时计划，上传配音无需在线或离线 TTS 包。

## 模型连接检查的边界

只有点击按钮才向当前 `OPENAI_BASE_URL` 的 `/models` 发送 GET，并携带配置的鉴权信息。不发送新闻正文，不创建脚本任务，不执行生成。成功时显示“模型已列出 · 生成待验证”。

区分鉴权拒绝、接口不存在、限流、超时、连接失败、重定向、响应异常及模型未列出。部分兼容服务没有 `/models` 或未列出全部模型，不能据此断言它不支持生成。

请求使用 3 秒连接/读取超时，响应最多读取 1 MiB 加 1 字节用于越界判定；这不是生成调用的超时设置。重定向不跟随，避免把鉴权信息转发到其他地址。地址中的账号、密码、查询参数和片段不用于此检查；请把令牌放在 `OPENAI_API_KEY`，使用最终兼容接口地址。

页面显示服务主机，省略 URL 路径、查询参数及凭据；检查结果不回显密钥、上游错误正文、数据库连接串或原始异常。这里只显示运行进程当前读取到的配置，不编辑 `.env`。修改配置后应重启服务；系统环境变量优先。

## 行为与接口

- `GET /api/setup/check`：本地配置和日程快照，无外部网络请求，不自动执行视频检查。
- `POST /api/setup/model-probe`：主动读取模型列表；不接受客户端提供的目标 URL 或密钥。
- `POST /api/setup/video-check`：本机视频能力检查；不合成配音、不渲染视频。
- 三个接口均返回 `Cache-Control: no-store`。上次配置保留在当前页面时，刷新失败会显示状态可能已过时。
- 页面为现有采集、选题、脚本审核、视频制作和作品留存提供入口。不创建、修改或启用策略/计划，不恢复或重试任务。

## 升级

停止旧服务并备份原数据库、运行目录与 `.env`。安装 `release/news2douyin-0.10.3-py3-none-any.whl`，或源码目录执行 `pip install -e .`。继续使用原数据库和运行目录启动，然后打开 `/setup`。

无新增数据库表、迁移和必需依赖，既有任务与制作流程保持原规则。外部新闻账户、真实模型输出质量和实际配音仍需在用户部署环境验证。
