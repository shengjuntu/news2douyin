# 0.29.0：从中文热点汇聚到选题

NewsNow接入从保存标题线索扩展为持续观察和具体议题汇聚。事件雷达内增加中文平台关注视图，与原有GDELT全球来源事件互补；四个主入口不变。可按关注、升位、最近观察筛选，展开平台位置、观察轨迹、原始链接与候选事件，确认或排除关联，再形成内容任务进入研究、创作和作品。

## 本版完成什么

- **具体议题归并**：使用规范化URL、标题相似度以及人物、行为、对象、数字和否定词等规则，优先避免把不同主张并成一件事。仅有“特朗普”这个共同人物不足以合并全部新闻；本版没有用LLM完成全局事件聚类。
- **可解释的关注指标**：分开记录本地观察时间、快照报告时间和条目发布时间。已识别的中文热榜参与关注分；快讯、自定义未知来源、全球技术榜与非新闻榜单不混为中文受众热度。来源失败、未返回、缺少历史和未知值明确显示，首次出现不计算正增长；重复缓存不制造位置升温。
- **有界的GDELT候选关联**：在有限的近期来源记录中，以同文档URL，或主体、宽泛行为与地区/日期等条件召回。保留匹配方法、依据、范围与截断说明。人工确认/排除可以保留；确认关联不代表报道已核实，无匹配不代表没有相关事件。
- **专题范围召回**：可以按已有专题关键词查看相关议题，遵守范围版本和回收站状态。这里只是候选召回，不自动加入正式专题材料、不触发深度研究。
- **分层保存与恢复**：完整快照继续内容寻址保存；DuckDB记录观察历史，PostgreSQL保存小型队列、当前议题与选择，FalkorDB在既有全局图保存有界关联投影。处理失败保留可重放输入，不在HTTP页面内打开DuckDB、重扫原档或等待图投影。

关注分是所见列表位置的代理值；升位分是同源、同条目的位置变化分，**不是传播增长率、每小时速度、搜索指数或播放量**。NewsNow标题和摘要仍是待补原文线索，不能直接冒充核实证据。公式与模型见[关注议题说明](ATTENTION.md)。

## 升级与使用

按原部署流程停服务并备份数据库、完整`storage_root`、配置和图卷。保留原事务库地址、存储目录与图命名空间，用实际服务Python安装：

```bash
python -m pip install --upgrade "./release-0.29.0/news2douyin-0.29.0-py3-none-any.whl[research]"
python -c "import importlib.metadata,news2douyin;print(importlib.metadata.version('news2douyin'));print(news2douyin.__file__)"
```

Editable部署须完整更新源码和`pyproject.toml`，再重新安装`pip install -e .`。启动自动建立新增的attention业务表，不更换数据库，不删除历史文章、事件、专题或原档。全局图的新标签定位索引仍由后台增量检查，HTTP启动不等待图构建。

默认`NEWS2DOUYIN_ATTENTION_ENABLED=1`。正式NewsNow采集完成后，后台读取已冻结的完整快照；试跑不会发布关注议题。旧正式采集记录通过主键分页在后台发现，保留断点，不在Web启动扫描全部历史。快照或校验信息缺失会报告错误，不补造旧观察。进入雷达查看关注议题与处理状态，再按需形成选题。

`POST /api/attention/rescan`只重置历史清单发现游标，重新发现时复用已有队列身份；它不删除处理状态，也不强制重算已经完成的清单。关闭attention后台只暂停这条派生链路，采集计划、原档和既有内容任务继续保留。具体状态、接口与恢复边界见[说明](ATTENTION.md)。

## 验收边界

开发验证使用本地受控NewsNow HTTP样本和独立测试数据库/图；它验证数据管道和恢复契约，不代替现场平台覆盖验收。没有在本版开发过程中部署用户主机、删除历史数据、访问用户私网NewsNow，或声称获得百度/微信指数、真实平台播放量。

匹配有读取上限，规则有词表覆盖限制，图只保存近期有界导航数据。PG、DuckDB、原档和图须作为同一部署数据集保留；后台积压、失败和覆盖不足应在页面查看，不能把空结果直接解释成“没有关注”。
