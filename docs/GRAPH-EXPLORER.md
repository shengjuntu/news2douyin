# 浏览全局活动图与焦点图

导航的「图谱」先打开全局活动图。切到「焦点图」后可以选任一焦点，暂停的焦点仍可查看。在焦点页点击「查看图谱」会直接打开它的图。

- 滚轮缩放，拖动背景平移，拖动节点调整位置。「适合视图」将图居中。
- 用节点搜索框或类型图例查找当前图中的节点。点击点或列表项查看关系、方向、来源链接，以及投影中已有的理由或证据。
- 默认最多读取 240 个节点，可选择更大的上限，最高 800。达到节点、关系或邻域读取上限时页面会提示。全局活动图展示近期已整理事件，以及已投影的 GDELT 编码和中文平台关注。焦点图从当前关注问题和归集的材料进入。

服务端分批读取现有 FalkorDB 投影，达到时间预算时保留已读取的图数据。没有可用的图数据时，界面会标明原因并显示关系库快照。图谱页面提供只读操作，拖动坐标只影响当前视图。

## 查询状态和耗时

「图查询超时」表示 FalkorDB 停止了超时查询。「等待图数据库返回超时」表示应用在连接等待时限内没有收到响应。连接失败、图归属不一致和样本上限各有单独提示。图中还可通过状态栏确认当前数据来自 FalkorDB 或关系库快照。

以下设置仅用于图谱浏览页，单位均为毫秒。

| 环境变量 | 默认值 | 可设置范围 | 用途 |
| --- | ---: | ---: | --- |
| `NEWS2DOUYIN_GRAPH_EXPLORER_QUERY_TIMEOUT_MS` | 600 | 50–5000 | 单条 FalkorDB 查询时限 |
| `NEWS2DOUYIN_GRAPH_EXPLORER_BUDGET_MS` | 1800 | 200–10000 | 单次请求的图查询总预算，预算用尽后停止提交新查询 |
| `NEWS2DOUYIN_GRAPH_EXPLORER_SOCKET_TIMEOUT_MS` | 1000 | 100–6000 | 图谱浏览页使用的连接等待时限 |

最后一次已发出的图查询可能继续等待连接返回。增大查询时限时，要结合连接等待时限和整次读取预算调整。

Cosmos.gl 3.6.0 的浏览器包随应用安装，由服务端提供静态资源。浏览器无法初始化 WebGL 时，可以用同一页面的节点列表和关系详情查看材料。[Cosmos.gl 项目与文档](https://github.com/cosmosgl/graph)
