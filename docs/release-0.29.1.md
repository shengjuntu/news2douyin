# 0.29.1：采集链路稳定性修复

本版针对现场0.27.0升级报告中的长标题索引错误、投影积压及Events下载缺少诊断信息，修复数据处理链路。它是完整源码与安装包，可以从0.27.0直接升级，包含0.28/0.29的NewsNow接入与关注议题功能。

## 修复内容

- **长标题与旧库索引**：保留完整`Event.event_title`，移除不必要的全文B-tree声明；`Article.source_domain`同类索引也移除。正常启动在业务写线程启动前，核对并清理这两个旧版索引。不会只改模型而把旧索引留在现场，也不会截短新闻标题。
- **受阻批次独立退避**：确定性数据错误或不可读归档会留下批次、阶段、行号或预读范围、错误和重试时间。当前处理块仍原子回滚，游标不越过未知材料；其他种类和同类的后续可用批次继续推进。数据库连接、锁和事务并发错误交给外层退避，不反复抢锁写错误状态。
- **GDELT下载证据**：每流保存最近一次请求的阶段、实际URL、清单列出URL、目标和最新批次、HTTP状态、校验预期与错误分类。404不再被解释成已经确认的永久缺档。显式探测比较当前目标与最新清单，不改变接收游标，也不把探测HTTP200当成归档成功。
- **进度口径与读取成本**：接收页区分原始归档、游标已处理、等待投影和未完成批次。状态刷新不再全表统计百万级回执或文章版本；打开页面不自动扫描接收库。新版本以来的成功/跳过分项在写入事务内更新，旧库历史分类无法精确还原时显示未知。
- **可核对的阶段观测**：最近处理块显示选批、接收库读取、准备、SQL锁与应用阶段。提交耗时在当前进程可观测，重启后未知；这些数据帮助定位瓶颈，不承诺现场已经追平积压。
- **减少数据库往返**：投影回执按当前有界处理块批量读取键值，避免逐行重复查询；官方Events/Mentions不再读取未使用的文章归档引用。主体写入仍保留原事务与重放约束，不以扩大事务冒充吞吐提升。

完整契约、接口和现场采样方法见[采集故障与恢复](INTAKE-RECOVERY.md)。

## 升级

按原部署方式停应用服务，备份数据库、完整存储目录和配置，再更新完整源码或安装本包wheel。保留原`.env`、数据库地址、`storage_root`和图命名空间。不要用覆盖源码的操作删除现场数据目录。

```bash
python -m pip install --upgrade --no-deps ./release-0.29.1/news2douyin-0.29.1-py3-none-any.whl
python -c "import importlib.metadata,news2douyin;print(importlib.metadata.version('news2douyin'));print(news2douyin.__file__)"
```

Editable部署更新完整源码后，使用实际服务环境运行`python -m pip install -e . --no-deps --no-build-isolation`，然后重启服务。此安装方式要求当前环境已经有构建依赖。项目依赖集与0.29.0相同。

启动会自动建立新增的小型投影控制、计数和下载诊断表，并执行`database.text_index_safety`阶段。索引迁移只检查系统目录，不扫描或重建文章、事件大表；PostgreSQL局部锁等待上限2秒。若旧写进程仍持锁，或同名索引已被定制为不同定义，启动会给出明确错误并保留原索引，待处理后重试。索引删除和已有文本数据是不同对象；本版不删除文章、事件、专题或原档。

相对0.29.0，新增四张伴随表：`intakeprojectionfailure`、`intakeprojectionmeter`、`intakeprojectioncounter`、`intakefetchdiagnostic`。它们保存错误与小型状态，不复制原始全文；从0.27升级还会补建0.29的关注议题相关表。

继续保留`NEWS2DOUYIN_GKG_AUTO_EVENTS=0`。这个开关限制GKG逐篇新建研究事件；已有链接仍可正常更新标题，此路径也纳入长标题回归。

## 验收边界

已修复的是代码、迁移与诊断机制。用户现场的具体404批次、TLS故障和实际接收/投影速率，需要升级后用新诊断核对，不能由受控样本替代。

`Article.canonical_url`既有索引本版保留，避免贸然移除旧身份回落查询所用索引；极长URL的索引限制没有在本版根治。此类确定性写入错误会隔离到受阻批次，保留原档和补处理缺口，其他批次仍可继续。后续替换为固定长度身份索引需要独立迁移设计。

所有开发验证使用临时数据库、图和合成HTTP/ZIP输入；没有在用户服务器部署、执行清理或调用真实LLM。默认页统计、主动网络探测、原始记录检索是分别触发的操作。
