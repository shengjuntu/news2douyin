# 热点

打开「事件雷达 → 热点」。按冲突、重要会议、自然灾害和广泛影响筛选，例如按交战双方跟踪冲突、按会议名归集多篇报道、按地点和时间识别同一场震情、按影响范围发现大范围停电或交通中断。

每张卡对比最近 36 小时与前一段 36 小时的去重报道数。展开「查看报道」可以看到来源和原文。多来源热点需要来自不同发布主体的报道。较大震级、紧急疏散或明确大范围中断等单一来源线索标为「单源待核」。GDELT 事件编码和中文平台观察可以提供相关线索，报道数量按可用报道单独计算。

点击「建立焦点」预填名称、描述和可编辑关注词。确认规则并保存后进入自有焦点，也可从具备候选编号的报道直接形成选题。焦点建好后，可以用现有 MCP 进一步按日期、国家、分类和来源归整材料。[焦点与 Agent 接入](FOCUS-MCP.md)

页面读取已发布日报、GDELT 事件及提及索引、已整理事件、采集报道和中文平台观测的限量样本。采集缺口、取样上限以及尚未入库的报道都会影响覆盖。筛选和归并使用本地规则，结果短时缓存。可以在页面底部查看采样来源和数量。

## 设计参考

所附 `GDELT_Risk_Analysis_Platform` 先计算按日的全球地缘紧张度，再按年度均值与标准差识别异常日期，并为异常日期附上历史报道。热点页借鉴了「近期变化、来源覆盖、原文入口」的组织方式。当前读的是单个议题的双窗口报道量，并为各类事件分别判断信号。按具体议题积累更长期的基线，可用于之后区分持续高关注和突然升温。
