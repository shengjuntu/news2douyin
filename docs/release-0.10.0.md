# 0.10.0：视频制作与作品库

本版将已有视频渲染整理成“选模板 → 配音与字幕 → 分段画面 → 检查并生成”的网页流程，并将视频列表升级为可检索、预览和管理的作品库。0.6–0.9 的每日采集、策略管理、事件脉络和脚本工作台继续保留。

## 直接使用

1. 在脚本工作台保存并审核当前稿，点击“制作视频”。
2. 选择新闻简报、解释说明或事件复盘模板，选择输出规格。
3. 选择离线机械配音、联网 Edge TTS，或上传 PCM WAV 配音和 SRT。
4. 根据分镜提示准备图片；可为每段指定图片，也可使用无图的信息卡。点击“更新画面预览”检查。
5. 点击“检查制作条件”。审核版本、素材、字幕及编码环境检查通过后，提交后台任务。
6. 完成后在作品库播放预览、下载 MP4、字幕或完整制作包。失败时查看恢复建议，再从已保存进度重试。

从已完成或失败作品点击“带入设置，制作当前稿的新版本”，可复用模板、配音和图片设置，但会明确显示本次使用的**当前脚本版本**。修改过的稿件仍需重新审核。原作品保留；段落已变化时，旧配图需要重新核对。

## 三套模板

| 模板 | 画面 | 用途 |
|---|---|---|
| 新闻简报 | 深色标题、蓝色提示、要点卡或图片、字幕与来源 | 每日快讯 |
| 解释说明 | 浅色背景、事实/分析标签、资料卡与字幕 | 解释已知信息与限制 |
| 事件复盘 | 节点序号、时间依据、时间线卡或配图 | 讲述事件进展 |

预览直接调用实际渲染布局，以 360×640 展示所选段落的第一条字幕，不调用配音服务。最终支持 360×640/12fps、720×1280/24fps、1080×1920/24fps。标题和辅助标签过长时会以省略号显示；口播不会因目标时长或标题空间而被删减。长 SRT 字幕无法容纳时会报错，请拆分字幕。

模板、参数、脚本审核版本、图片身份及哈希均在提交时固定。以后修改作品名称或脚本不会改掉正在制作的内容。

## 脚本段落与画面

- 0.9 的有据稿按 `segments` 分段展示口播、事实/分析类型、分镜和素材需求。每段可指定一张图片。
- 勾选的图片按页面列表顺序循环分配到未单独指定的段落。若不想自动配图，取消这些勾选，再逐段指定；其他段落使用信息卡。
- 平文旧稿视为一个画面段落；未单独指定图片时，继续按所选图片顺序分配到字幕帧。
- 自动配音先在段落边界分开，再按句合成。画面与字幕根据实际合成音频时长排列。
- 上传 SRT 必须与审核稿全文一致，包括分析段的“分析：”，每条字幕不得横跨两个脚本段落。跨段时明确提示拆成两条，并由使用者填写实际时间，不按字符比例虚构切换时间。
- 字幕之间的静音间隙保留上一段画面，开头间隙使用首段、结尾使用末段；这些帧没有口播字幕。画面编码有帧率量化误差。
- 发生日期、报道日期、未知时间与争议标签来自固定证据节点。多个节点的完整时间与说明保留在导出中；画面空间有限，不是完整证据阅读页。

模板仍是可用的静态信息卡与图片画面，不包含素材自动检索、视频片段剪辑、转场、背景音乐或自动发布。分镜提示不会被当成已取得的素材；图片由用户准备。

## 制作检查与失败恢复

环境检查现在实际运行 FFmpeg/FFprobe，并检查 libx264、AAC、Pillow 与中文字体。页面列出各项结果和安装/配置提示。可选配音依赖单独显示；没有自动配音依赖时仍可选上传配音。

制作预检进一步核对当前审核版本、图片和音频所属脚本、文件指纹、SRT 正文、跨段关系、时间顺序与音频长度。预检和单帧预览不创建视频任务，也不导出新的脚本制作包。更改设置后要重新预检；提交时服务器仍会重新检查，以防期间有人改稿。

失败或取消后，结果页可以检查原输入、素材、字体、配音分段、完整配音和完整产物检查点，并提示哪些可复用。原有队列的取消、租约、恢复与重试继续生效。完整配音已保存时，即使原上传 WAV 后来丢失，也能复用有效配音继续画面与编码；原图片、字体或输入不匹配时需恢复或另做一版。

重试使用原来的固定输入；换模板、图片或配音需新建任务。已成功的作品不原地重写。若产物文件丢失，恢复运行目录备份，或从当前审核稿另做一版。作品卡和详情会提示缺失/大小异常，下载还会验证 SHA-256。

离线 eSpeak NG 为机械音；Edge TTS 检查只确认依赖安装，未验证网络和远端语音可用性。上传 WAV 的 SRT 匹配也不能证明音频真实说了这些话，仍需试听。

## 作品库

- 按作品标题、备注搜索；按提交日期、制作状态、模板、收藏和归档筛选，支持分页。
- 默认展示已完成成片；切到“全部记录”或“制作中 / 排队中”可找到未完成任务。
- 封面、名称、脚本版本、模板、时长、尺寸和提交时间同卡展示；直接进入预览或下载 MP4、SRT、制作包。
- 日期查询按所选 IANA 时区处理，网页默认 Asia/Shanghai；结束日期包含当天。
- 可编辑名称与备注、收藏、归档和恢复。仅修改作品库信息，不重写视频、封面、字幕和原审核稿；归档不删除文件。
- 修改作品信息有版本冲突检查。多人或多页同时编辑时，旧页面会提示刷新，保留尚未保存的输入。

数据库只新增 `VideoWork` 表，并为已有视频补充作品名称和“旧版新闻卡”标签。旧制作输入、产物记录和审核稿不改写；尚未执行的旧版视频继续按原布局渲染。

## 输出

保留 MP4、WAV、SRT、封面、审核稿快照、制作清单和完整 ZIP。本版的新视频额外生成 `scene_timeline.json`，记录模板版本、各段口播、事实/分析类型、来源编号、节点时间、图片分配及每帧区间。`manifest.json` 增加模板与段落数量，仍含各产物校验值。

[真实离线配音示例](validation-0.10.0/demo/video.mp4)约 8.42 秒，含两段虚构资料与分析标记；用于验证功能，不代表真实新闻。完整文件在同目录，或查看 [制作包](validation-0.10.0/demo/video_bundle.zip)。

## 升级与运行

停止旧服务，备份原数据库、整个运行目录和 `.env`。安装新版本后继续使用原数据库和 `storage_root`，不要只拷贝数据库而遗漏媒体文件。

```bash
pip install -e ".[video,voice-offline]"
# 可选联网配音
pip install -e ".[tts]"
news2douyin-server --host 127.0.0.1 --port 18080
```

也可先安装 `release/news2douyin-0.10.0-py3-none-any.whl`，再在同一 Python 环境安装所需可选依赖。需要系统 FFmpeg/FFprobe 和中文字体；页面会给出缺失项，不会自动安装系统程序。

可配置 `NEWS2DOUYIN_FFMPEG`、`NEWS2DOUYIN_FFPROBE`、`NEWS2DOUYIN_VIDEO_FONT`。示例字体为本机 Noto Sans CJK，不随发行包内置。Windows 可使用本机微软雅黑等含中文字形的字体。

## 新接口

- `GET /api/video/templates`：模板目录。
- `POST /api/video/preview`：制作参数加 `scene_index`，返回 PNG。
- `POST /api/video/preflight`：核对制作条件，返回段落/素材数量与提示。
- `GET /api/video/works`：分页作品查询；参数 `query`、`status`、`date_from`、`date_to`、`timezone`、`template`、`starred`、`archived`、`offset`、`limit`。
- `PUT /api/video/works/{task_id}`：带 `expected_version` 修改名称、备注、收藏或归档。
- `GET /api/video/tasks/{task_id}/recovery`：只读恢复条件检查。

制作参数新增 `template=brief|explain|timeline`、`scene_images={segment_key: asset_id}`。旧接口 `/api/video/tasks` 继续返回原有任务列表形状，作品查询使用独立接口。

## 保留的边界

仍为本地 CPU 编码，任务与采集、脚本共用队列；不会凭本机安装状态承诺其他系统的渲染性能。最多 6000 字符、300 条字幕、600 秒、12 张不同图片；上传图片 20 MiB、PCM WAV 50 MiB。默认模板和作品库已完成，但专业声音质量、素材准备和内容核实仍需实际使用中调整。独立 RunDesk 视频 APP 本次未修改。
