# 0.10.1：每日选题后台生成

本版修复主流程中的一个可靠性缺口：0.9 的事件专题脚本已在后台生成，但每日选题仍同步等待模型。现在“生成所选脚本”会先保存整批请求，再由现有队列执行。页面关闭后可从每日选题、脚本工作台或任务列表返回。

## 使用变化

1. 在每日选题勾选新闻，选择基础摘录稿或 AI 中文初稿，点击“生成所选脚本”。
2. 单条跳到任务进度，完成后点击“打开生成草稿”；多条留在选题页显示每条状态。页面约每 3 秒同步选题和进度，后台任务按队列顺序执行。
3. 可随时离开页面。服务需保持运行；重启服务后，排队任务继续，意外中断的任务在租约恢复后续办。
4. 失败后在任务页点击“从已保存进度重试”。有效的生成稿检查点会复用，避免重复调用模型；尚未保存检查点的请求可能需要再次生成。

推荐每天 1–3 条，单批上限 20 条。所有选题校验成功后整批提交；存在无效选题、空正文或生成方式冲突时，这一批不会只提交一半。已经有稿的选题仍返回原稿，不覆盖编辑内容，也不会自动换成另一种生成方式。

## 重复提交、取消和切换方式

- 同一选题和生成方式重复提交，返回已有任务。响应丢失后可重新点击。
- 活跃任务使用另一种方式时返回冲突。先取消并等待结束，再选择新的生成方式提交。
- 失败或手动取消的任务可从进度页重试；再次点击生成且方式相同，只找回已有任务，不暗中重试。
- 移出选题会取消未完成的生成，并解除其与当前选题的关联。重新选中可创建新任务，旧模型响应即使晚到也不会保存到新选题。
- 移出选题不删除已有脚本和历史任务；重新选中已完成的选题仍能打开原稿。
- 若需要用报道的新内容重新生成尚未成稿的选题，移出后重新选择再提交。已生成稿件可在工作台编辑；本版不自动覆盖已有稿。

模型请求发出后，取消需等待请求返回或超时；取消状态会立即记录，结果保存前再次核对。多页重复提交、取消与生成并发时，通过数据库事务和任务租约保证仅保存有效任务的一份稿件。

## 固定输入与结果

提交时保存所选报道的标题、原文摘录、来源、版本与内容指纹，以及选题日期、时区和生成方式。其他报道不会因属于同一事件而被自动加入。后续采集更新原文，不会替换已提交输入。

AI 任务另固定模型地址与名称，API Key 不写入任务输入。执行时若地址或模型名称已变，任务会提示恢复配置或重新提交，避免使用新配置向旧地址发请求。生成稿、选题结果关联和任务完成状态一起提交，保存失败不会留下半份稿。

这保证输入与流程可追溯，不证明模型生成内容在语义上完全正确。基础稿保持原文语言，AI 初稿仍需核实、编辑与审核。

## 接口与兼容

- `POST /api/daily/script-tasks`：`{"selection_keys":["选题键"],"mode":"basic|llm"}`。返回 `items`，每项包含选题键、任务、稿件链接及是否复用；有待生成结果时返回 202，全为已有稿时返回 200。
- `POST /api/daily/selections/{selection_key}/script-task`：单条入口，正文为 `{"mode":"basic"}`，返回相同列表结构。
- `GET /api/daily/script-tasks`：历史任务，可按 `day`、`timezone`、`limit` 查询。
- `GET /api/daily/script-tasks/{task_id}`：固定来源摘要、进度、结果、是否仍关联当前选题与能否重试。
- `/api/tasks/{task_id}`、取消、重试和 SSE 沿用现有接口；任务 `kind` 新增 `daily_script`。
- `/api/daily/selections` 保留原有字段，新增可为空的 `generation` 状态信息。
- 旧同步 `/api/daily/selections/{selection_key}/build` 保留；存在当前后台任务时返回 409，已有脚本则复用。旧脚本、事件生成、采集任务与视频接口继续保留。

## 升级

停止旧服务，备份数据库、运行目录和 `.env`。安装 `release/news2douyin-0.10.1-py3-none-any.whl` 或在源码目录执行 `pip install -e .`，继续使用原数据库和运行目录启动。

本版新增 `DailyScriptGeneration` 表，不重写现有选题、脚本、视频输入或作品备注。所需新闻和模型配置保持不变；不新增必须安装的依赖。视频可选依赖和编码环境沿用 [0.10 视频说明](release-0.10.0.md)。
