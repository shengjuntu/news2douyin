# 导出每日精选供 Codex 选题

在「事件雷达 → 每日精选」选择北京日期，再点页首的 Markdown 下载按钮。清单包含该版所有入选卡片，默认上限 100 条，只有 37 条就导出 37 条。分组和浏览顺序仅影响页面，文件始终采用日报发布时的推荐顺序。

在后台更新期间，页面仍可下载上一份已发布的日报。新版本一旦发布，旧版下载链接会提示返回当期页面。录制前可自行保留所用的 Markdown 版本。

可直接查看 [11 月 15 日第 2 版的百条 Markdown](validation/0.36.1/news2douyin-daily-100-2026-11-15.md)。这份回放覆盖两个公开的英文 GKG 批次，保留该期实际收到的标题和原始来源链接。

## 命令行与 HTTP

```bash
news2douyin-daily-radar export --day 2026-11-15 --out ./briefs/daily-100-2026-11-15.md
```

省略日期即取北京时间今天。HTTP 下载地址为 `GET /api/radar/daily/{day}/shortlist.md?revision={revision}`。网页与命令行都使用已发布的清单，文件包含已有的中文译读。后续完成的译读可以在下次导出时出现。网页和命令行导出均不会触发模型任务。v0.36.0 的 `brief` 命令和 `brief.md` 下载地址继续兼容旧脚本。

## 交给 Codex

可直接给出这样的要求：「阅读这份每日精选，从中选出今天值得做视频的十件事。每件写明原清单序号和链接。把报道同一次行动的材料放在一起；分别说明今天新增的事实、影响对象及待核问题。选题前核对原文，标明具体行动日期。对无法核实或只有标题的材料保留待核状态。」

将采用的条目标识和另行找到的重要事件记录下来，可用于以后评估百条清单覆盖。Codex 没有采用的条目仍可能有价值。[百条名单的改进与评估](SHORTLIST-QUALITY.md)

想比较另一种百条选法，可以将同一期的三份实验名单与已发布清单对照，并把组合结果导出成一份供 Codex 使用的 Markdown。[百条对照](SHORTLIST-TRIAL.md)
