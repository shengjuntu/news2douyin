# 0.6.0：恢复每日选题到脚本的使用流程

## 为什么改

早期版本包含采集、评分、选题与脚本导出流程，还提供选题复核脚本。0.5.0 已有长期采集、新闻库、事件、脚本版本和视频制作，但网页以运行管理为首页：采集后只能去看日志，选题没有独立状态，脚本入口藏在事件详情中。它具备多个环节，却没有形成每天实际使用的路径。

## 现在怎么用

1. 启动服务，打开首页“每日选题”。已有策略直接选择；无策略时到“采集策略”新增。
2. 选择日期和策略，点击“采集所选日期”。任务在后台执行，任务页展示进度和失败信息。
3. 完成后点击“选择本次新闻”。该列表包含本批次保存和重复抓取的报道，即使没有新文章也能继续选题。失败或取消的任务可以查看已完成入库的部分。
4. 勾选当天计划制作的新闻，建议每天 1–3 条。选择保存到数据库，切换查询、分页、刷新和重启服务后仍可继续。
5. 选择“基础摘录稿”或“AI 中文初稿”，点击“生成所选脚本”。一条选题对应一份脚本；多条依次生成。已有脚本会被复用，不覆盖编辑内容；取消选题不会删除已经生成的脚本。
6. 打开脚本，编辑口播和画面提示，核对来源、提交与通过审核。可导出制作包，或进入现有视频制作页生成、预览和下载 MP4。

## 两种脚本生成方式

| 方式 | 实际能力 | 依赖 |
|---|---|---|
| 基础摘录稿 | 提取选中报道的标题和正文片段，生成口播初稿、画面提示与来源快照；保留原文语言 | 无模型依赖 |
| AI 中文初稿 | 通过兼容 Chat Completions 的模型生成中文口播和画面提示；只提供已选报道作为资料 | `OPENAI_BASE_URL`、`OPENAI_API_KEY`、`MODEL` |

默认基础稿不冒充深度分析或翻译。AI 返回格式错误或连接失败时不保存失败结果，也不自动改成模板假称生成成功。可重试或改选基础稿。生成后的初稿仍需核对。

脚本来源只绑定选中的报道及版本、内容哈希。事件关联中的其他文章不会自动混入。来源截取沿用现有上限 2000 字符，因此当前不等于阅读了完整原文。原来的事件页模板生成和审核/导出 API 保持兼容。

多选生成目前由页面依次调用接口；关闭页面后尚未提交的后续条目不会继续执行。每条已保存的结果可重试复用；模型生成还没有接入持久后台任务队列。视频与采集仍使用原有后台队列。

## 日期筛选

新闻库新增：不限、今天、昨天、近 7 天、近 30 天、自定义起止日期。

- 发布时间：新闻来源标注的时间。缺失日期的报道不进入指定发布日期范围。
- 采集时间：采集批次时间，支持同一文章在不同日期被重复采集；队列任务用提交时间，直接运行用开始时间。没有批次账本的旧文章回退到最后抓取时间。
- 首次入库时间：文章第一次保存到本系统的时间。
- 默认时区为 `Asia/Shanghai`，可通过 `NEWS2DOUYIN_TIMEZONE` 或查询表单指定其他 IANA 时区。日期包含起止两天，转换到 UTC 后按左闭右开区间过滤，支持夏令时。
- 先筛选后分页，翻页保留关键词、日期和时区。重置会清除日期条件。

每日选题默认展示选题日采集的新闻，也可以切换为当日发布。“选择本次新闻”按批次列出结果，不因发布日期较早而隐藏；页面会明确提示当前正在看本次采集。

后台提交时会把当前当地日期固化到任务快照，重试不会跨天换日期。定时任务使用其配置的时区和触发日。新版采集显式请求指定日期，空结果不会静默请求昨天。新闻源如何归属其日榜日期由新闻源决定，不保证精确对应每篇报道在你所在时区的自然日，原始发布时间仍保留可查。

## 策略管理

页面支持新增、编辑、复制，字段包括新闻源、国家、语言、分类、关注/排除词、来源白黑名单、最大条数和主题标签。编辑时保留高级选项；已经排队的任务仍使用提交时的快照。

`cn_policy_sectors` 是中国政策与板块策略，`us_market_macro` 是美国宏观与市场策略，均为示例配置。当前真实 provider 是 WorldNewsAPI，mock 仅用于演示。国家、语言和日期用于上游热门新闻接口，其余主要是本地过滤：这不是按关键词主动检索全网。数量上限在过滤前截取，过严的策略可能得到零条。

删除/停用策略、关联任务检查、策略试跑诊断和一体化定时编辑留到 0.7.0。已有定时任务的新增与启停仍可在“运行管理”使用。

## 导航与模块定位

首页改为每日选题，原仪表盘移到 `/admin`；管理和调试入口仍可从页脚进入。脚本列表展示标题；脚本与视频空状态说明前置步骤并提供入口。事件专题说明报道关联及其时间含义；原“时间线”移至辅助工具并改名为“新闻长图排版”。真正的事件发展脉络尚未实现，见后续版本计划。

## 升级

1. 停止原服务，备份原数据库与整个 storage_root。
2. 解压新包，在现有 Python 环境安装 `pip install -e .`，或安装 `release/news2douyin-0.6.0-py3-none-any.whl`。视频需要原来的可选依赖和 FFmpeg。
3. 保留原 `.env`、数据库和 storage_root 路径，用原启动参数重启。新版本自动新增选题表，不重写旧新闻、脚本和视频。
4. 首页检查已有策略，采集一次，然后选一条新闻生成脚本。已有脚本继续在 `/scripts`，已有视频在 `/videos`。

不把早期包的 `.env` 或凭据复制到本发布包。本次保留 Python + HTML 技术栈，没有迁移 Go，也没有连接或改动独立 RunDesk 应用。

## 新接口

- `GET /api/daily/selections?day=YYYY-MM-DD&timezone=Asia/Shanghai`
- `POST /api/daily/selections`：`article_key/day/timezone/active`
- `POST /api/daily/selections/{selection_key}/build`：`mode=basic|llm`
- 新闻查询增加 `period/date_from/date_to/time_field/timezone/task_id/profile_name`，保留旧数组响应和分页契约。

验证范围以 SQLite 为准；日期查询使用 SQLite 日期函数。当前数据库没有多用户隔离，选择状态属于当前服务实例。
