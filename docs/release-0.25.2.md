# 0.25.2 发布说明

本版修复v0.25.1在非C排序PostgreSQL中漏取投影任务的回归，将专题整图重写改为持久化分批核对和按指纹增量写入，并补齐真实维护状态和启动诊断。继续保留全量GKG、PostgreSQL＋DuckDB＋FalkorDB架构、文字建题和原迁移工具。

## 队列排序兼容性

旧实现的`event/ ≤ key < event0`默认使用数据库排序规则，在现场`en_US.utf8`下会排除真实事件。新实现的范围、游标与ORDER BY统一使用显式C排序，并在后台并发建立匹配的新部分索引`ix_graphpending_pending_key_c_v2`。保留旧索引，不改变整个数据库的collation；已有同名但定义不同或无效的索引报错，不擅自删除。SQLite保留原兼容索引。

QA启动器新增locale参数，分别在实际C和en_US.utf8数据库运行；稀少专题在2万待办事件中的查询检查Index Cond与过滤行数，不能只凭Index Scan名称判断快速定位。

## 专题投影

- 按阶段和材料键分页，每批保存检查点并释放全局图写入租约；新事件和其他专题可在批次间执行。
- 比较材料指纹，仅重写变化的图材料。SQL仍按有界页完成专题核对，不声称端到端O(变化项)。
- 连续到来的消息不再仅因token变化就重置当前轮；完成后仍只条件确认捕获token，新变更不会被误确认。
- 支持进程重启续做、外部图写入后中断重放、途中排除成员、范围版本变化、共享文章、图丢失恢复和明确重建。
- 既有专题图首次采用新机制时分批盘点旧业务节点；不清空图、无需重新采集新闻。
- 新增`GraphFocusState`、`GraphFocusReceipt`；新增GC控制表见后文。新增表会随正常schema初始化创建，无需改写原业务表，迁移工具支持保留这些检查点。

## 可用性与诊断

仍沿用原入口，不新增菜单。知识处理状态的折叠详情分别显示事件耗时、专题批次耗时、完成确认、分批进度，以及GC暂停控制。专题批次完成不等于整个专题已同步，混合均值不再标作每事件耗时。

启动日志分阶段记录SQL初始化和工作线程启动；`/api/system/startup`可读取诊断，健康检查不等待图就绪。历史抽取回填增加事务检查点，相同模式重启不再重复全量GROUP BY。首次升级仍需回填一次；必要schema、触发器和缺失搜索索引仍同步初始化，现场两分钟启动是否消除仍需实际日志验证。

## 图清理控制与诊断

- 知识处理状态页新增暂停、继续自动清理。暂停独立保存于新增`GraphGcControl`表，覆盖同一命名空间下的全局图和专题图；事件采集、抽取及图投影继续运行。
- 正式暂停不再通过把扫描状态写成`complete`实现。保留原扫描游标、上界、周期、计数及错误退避；正在执行的批次允许完成并保存检查点。继续操作从保存位置处理，不主动重启扫描周期。
- 新增`NEWS2DOUYIN_GRAPH_GC_ENABLED=1`。设为0只关闭孤立节点维护，保留扫描检查点；页面不能覆盖服务配置的关闭状态。
- 分开记录执行计划、高水位、候选读取和删除四个阶段的耗时、错误与超时，避免将所有500毫秒超时都归因于候选窗口。诊断是进程内的有界统计，重启后重新累计；最近失败是历史记录，不代表当前仍失败。
- 修复恢复扫描时执行计划检查失败可能导致后续重置扫描高水位与周期的问题。

本版不清空图、不删除原始GKG或历史文章。已有现场若曾手工把GC扫描标成完成，该状态不能作为扫描已完成的证据；升级不会猜测并覆盖原检查点。请用正式暂停入口管理后续维护，保留原操作记录后再核对被修改的状态。

每标签每周期的高水位聚合仍不是有界读取，维护仍使用独立超时、原全局图写入租约及严格原生ID定位检查。详见[图投影和维护说明](GRAPH-MAINTENANCE.md)。

## 升级与验收

先停止服务并备份数据库、配置、完整存储目录与FalkorDB持久数据。保留原DATABASE_URL、storage_root、FALKOR_URL、GRAPH_PREFIX及原`.env`；本版不要求切换图命名空间、删历史数据或降低全量采集。

推荐安装归档内的新wheel，避免反复覆盖旧src目录残留文件：

```bash
python -m pip install --upgrade "./release-0.25.2/news2douyin-0.25.2-py3-none-any.whl[research]"
python -c "import importlib.metadata, news2douyin; print(importlib.metadata.version('news2douyin')); print(news2douyin.__file__)"
```

使用实际服务的Python环境执行。若以源码editable方式运行，应使用完整新版源码及pyproject重新`pip install -e .`，核对上述模块路径。不要把备份目录直接`cp -a backup src`到已存在的src上，该命令会产生嵌套目录，不是恢复。保留旧安装包和备份用于回退。

首次启动观察新队列索引与各图索引就绪、事件/专题独立耗时、专题分批进度、待办净变化和Web响应；正式暂停GC后确认游标保存，再继续检查。旧现场手工假完成状态不会被新版自动修正。

验证记录与可复现实验见[0.25.2验证说明](validation/0.25.2/README.md)。本轮未访问或修改现场数据库，没有用本地合成结果承诺积压追平天数。图排名/聚类仍等待全部投影待办清空，分析最多覆盖最近5000事件；持续全量流下可能延后，本次没有将分析改为持续增量发布。
