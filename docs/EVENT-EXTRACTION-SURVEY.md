# 从新闻文本到持续专题综述 · v0.19.0

## 对原设计的评述

全局活动图与每专题知识图值得保留。它们给发现新事件和围绕同一个问题长期积累材料提供不同入口。v0.18.0 把报道归为事件包，保留来源、版本、人工选择和历史链接，适合作为升级基础。仅靠名称共现无法区分本人行动、他人评论和未经证实的传闻；根据报道量直接推断重要度会放大转载。多篇英国媒体报道华沙的一件事，也不能据此推出行动发生在英国。

本版在已存档的报道版本与研究判断之间增加“动作陈述”。每项有触发词、角色、状态、原句、字段和偏移量。较高的图连接度帮助找资料；事件是否真的发生，仍需要来源与相互印证。研究围绕可持续存在的子问题组织。聚类候选、人工问题大纲、研究报告保留各自的身份。

## 对照研究与工程取舍

| 原始研究 | 文献结论和适用边界 | 在本项目采用的做法 |
|---|---|---|
| Li、Ji、Han，NAACL 2021，Document-Level Event Argument Extraction by Conditional Generation | 论元可能位于同一文档的其他句子。WikiEvents 含事件与共指标注。论文指标来自指定数据集。 | 以动作及角色抽取；可选模型读取编号段落，跨段指代必须另给定位得到的原句。规则仅绑定较明确的局部角色。 [原文](https://aclanthology.org/2021.naacl-main.69/) |
| Saurí、Pustejovsky，Computational Linguistics 2012，Are You Sure That This Happened? | 新闻文本中的事实性与说法来源、否定及模态相关。 | 将发言与发言内容拆开，独立记录说法来源、计划、否认、可能、条件与报道描述已发生。核对“原文这么写”与核实世界事实仍需区分。 [原文](https://aclanthology.org/J12-2002/) |
| Strötgen、Gertz，SemEval 2010，HeidelTime | 可分别处理时间表达的识别及规范化，并按语言线索与规则恢复日期。 | 保留时间原文。已知原发布时间才解析“昨日”“下月”等相对日期。缺年份的月日只有和发布时间同月同日时才补年。当前实现支持有限中英文表达，未集成 HeidelTime 软件。 [原文](https://aclanthology.org/S10-1071/) |
| Event-Driven News Stream Clustering using Entity-Aware Contextual Embeddings，EACL 2021 | 对英文新闻流，稀疏、向量与实体信息可以共同支持聚类决策；此任务评测对象是报道文档。 | 陈述级候选采用动作、状态、精确到日的日期、角色以及地点的组合。仅在同一范围且证据版本有效时作一跳扩展；身份不明、缺日期或条件不符时不强行合并。 [原文](https://aclanthology.org/2021.eacl-main.198/) |
| Caselli、Vossen，2017，The Event StoryLine Corpus | 故事线上时间关系、因果关系需要独立标注，属于比主题聚类更细的问题。 | 按日期查看，分开已报道、计划与否认。相似陈述保留各自网页与摘录，不从共现或时间相邻自动创建因果边。 [原文](https://aclanthology.org/W17-2711/) |
| Yuan、Zhu、Zhang、Peng，Findings of EMNLP 2026，SurveyGraph | 学术方法实体图贯穿检索、大纲、叙事；自上而下模板与自下而上聚类组合，限定关系种类与一跳预算。160 个生成句的人工审计中，80.6% 属于有锚定或部分支持；108 条语义边中，68.5% 获支持或部分支持。它们并非新闻事实核验正确率。 | 用户维护的长期问题作为大纲骨架，报道动作及状态形成候选分组。按节融合原文词项、专题归属与受限的一跳候选，固定截止日期、选入理由、原文版本与研究段落。边须有可审查依据。 [原文与实验](https://aclanthology.org/2026.findings-emnlp.396.pdf) |

SurveyGraph 的核心对象是学术方法，关系描述方法之间的继承、竞争或共享资源。新闻报道常常在复述、否认、预告同一项行动，且后续更正会改变证据。因此新闻适配保留“某个版本里是谁怎样说”的陈述层。论文中的引用数、PageRank、HDBSCAN 和论文语义边分类器没有被直接移植。本文的混合检索和规则是可复验的工程基线，不继承论文报告的性能。

## 操作

1. 升级后沿用原 SQLite 和运行目录启动服务。旧文章最新版本自动进入后台抽取，之后每个新增版本独立处理。默认规则无模型调用。报道详情可逐项核对、排除或恢复；手动核对按具体内容和版本保留。没有动作的报道可以继续用于关键词匹配。
2. 报道详情点“用已配置模型重新抽取本版本”。使用已有 OPENAI_BASE_URL、MODEL、OPENAI_API_KEY 的聊天接口。将 NEWS2DOUYIN_EVENT_READER 设为 model 可让新处理的版本在规则完成后自动送模型。模型采用最多 1,200 字标题与 12,000 字正文、原文编号段落、限定 JSON 类型；角色可以引用同一版本的另一段。“原句出现”验证的是摘录保真，角色语义与事实性仍可人工核对。请求失败或证据校验失败时保留已有结果，页面可重试。没有正文时只读标题，GDELT 收录时刻不能替代原发布时间。
3. 专题内可建立有父子层级的长期问题；同一问题可在不同日期指定补查，回执与证据保留。人物专题优先展示本人作为行动人、发言人或参与者的命中，标题提及但角色不明仍可保留。按原句解析出的日期和人工整理的历史脉络分别展示。
4. “预览综述大纲与证据”按当前专题范围、人工排除和所选 UTC 截止时刻，取当时已归档的最新版本。最多检查 250 篇、展开 12 个长期问题及 5 种材料分组，每轮最多 12 篇种子报道。每节先找直接命中，再考虑同动作、状态、日、角色和地点的候选，标明来源是否已经人工核对。缺口与预算不足分别显示。手工大纲可长期保留，自动分组不修改手工树。
5. 提交后，实际选入的版本、段落编号、来源与缺口冻结在研究案卷中。报告生成时仍需运行中的 RunDesk、模型账号与搜索配置；研究侧继续校验 claim、摘录与段落。按历史截止时间预览时使用当前专题规则与人工审订，不能还原某一历史时刻的整套编辑决策。
6. 查图模式可访问 GET /api/desk/graph-schema。机器可读图字典随包提供；同一路径返回候选陈述的 JSON Schema。正式记录在 SQLite，配置了 FalkorDB 时两个图同步 Article → EventMention → Argument；少量确定的名称映射至 Referent，满足严格候选条件的陈述连接 OccurrenceCandidate。专题图增加 OutlinePoint → 下级 OutlinePoint 和指向补查任务的关系。名称未可靠消歧时仅保留表面写法。

## 可复核的结果和限制

真实历史归档取 GDELT GKG 原语种流 2025-02-03 19:45 UTC。用 rare earth 检索的 8 篇历史报道归入 3 个既有事件，实测全局图与两个专题图均能查询新陈述和角色。该批案例检验了数据流。

另取同批前 250 条索引记录，对 5–24 词的 ASCII 标题按 URL 的 SHA-256 排序并去除相同标题，在含广义动作提示词与其他标题中分别取 12 和 10 条。人工按题面标注七类真实世界动作和报道状态，一条标题可以有多个动作。原始标签、记录 ID 和复测工具随包，未附新闻原文。复测时，提供官方归档 20250203194500.gkg.csv.zip 并运行：

    python tools/evaluate_event_reader.py /path/to/20250203194500.gkg.csv.zip

初版规则在这 22 条开发标题上命中 5、误报 2、漏报 11。错例提示英语表态与决定的变形、名词化抗议、电话会谈覆盖不足。修订触发形式及部分语法范围后，在同一份开发样本上命中 15、误报 1、漏报 1；开发结果不能用来估计泛化效果。

保留修订规则后，从同批中按相同顺序继续取另 10 条带提示词、10 条不带提示词的标题。先人工标注其类型和状态，再评测。记录 ID 与开发组互斥，其中两条描述同一条联合国新闻。这是单批次、单人标注的英文标题检查，不能外推到中文、多日期、完整正文或角色级准确率。可在上述命令后加 `--labels tests/fixtures/event-reader-holdout.json` 复测。

| 20 条留出标题 · 14 个标注动作 | 命中 | 误报 | 漏报 | 精确率 | 召回率 | F1 |
|---|---:|---:|---:|---:|---:|---:|
| 修订前 | 5 | 2 | 9 | 71.4% | 35.7% | 47.6% |
| 本版规则 | 7 | 3 | 7 | 70.0% | 50.0% | 58.3% |

离线规则适合作为初筛，名词歧义和没有明确动词的真实事件仍会造成误差。模型接口用可控 HTTP 服务检查协议、错误、逐字证据及重试；线上真实模型的质量与成本需在目标部署另测。对新闻专题使用的逐节一跳检索可在 SQLite 的关系索引上运行，FalkorDB 保存对应的类型化节点与边。学术综述场景的 HDBSCAN、向量检索、中心性与句级引用审计指标均未在这个标题小样本上复现。

固定版冒烟测试见 tests/test_event_reader.py。覆盖同句两事、计划与否认、跨段角色的第二依据、历史截止、旧版本纠错、人工排除、跨报道候选、同一长期问题再次补查、实际冻结段落、一跳扩展以及无支撑的分节留空。以上不代表新闻事实准确率、生产召回率或最终综述质量。
