# 对照两种百条筛选改动

[八天实测及漏选实例](validation/0.37.0/PUBLIC-SHORTLIST-REPLAY.md) · [可直接交给 Codex 的 11 月 15 日试验清单](validation/0.37.0/news2douyin-trial-100-2026-11-15.md)

准备好已发布的某日日报，在能读取同一工作库和采集档案的位置执行：

```bash
news2douyin-review compare-shortlist --day 2026-11-15 --out review-2026-11-15
```

命令使用服务配置中的数据库和存储根目录，也可显式传入 `--db-url` 和 `--storage-root`。`--out` 选择新的目录，以保留以前的标注。每次保存最初读到的日期、版次、截止时刻。在同一批候选、历史补采范围和前七日已读排除条件下，程序分别试跑原排名、仅前置粗分类、仅合并行动和两项同时启用。基线若与已发布名次、现存候选计数或所存代表材料相异，需使用当时的工作库和档案快照重放。旧版储存的分组计数与入选证据能支持基线校验；落选材料的全量历史版本仍取决于档案。

| 文件 | 如何使用 |
| --- | --- |
| `shortlist.md` | 组合试验按推荐顺序排列的完整候选清单，含原始条目标识及保存的关联报道。可以交给 Codex。 |
| `review.html`、`review.csv` | 打乱四组代表和榜外样本。先打开网页逐条判断当天是否值得读，给同一项具体进展填写相同组名。确认独有时选择“核对同日后确认独有”。浏览器可导出 `ratings.csv`。 |
| `comparison.json` | 查看四种排名的稳定键、名次、分数、原文、换入与换出，以及扫描边界和各自的归并明细。 |
| `merges.jsonl` | 两个归并组的完整判定，每行含代表 ID、并入条目、原标题和所存来源，含卡内显示上限以外的成员。 |
| `merge-review.csv` | 按组分别列出每次合并。复核整体误合并时，可按代表 ID、成员 ID 去除两组同时命中的重复样本。逐对核对主标题和并入材料。对确属同一具体行动填 `same_development=1`；包含另一条独立进展填 `0`，在 `note` 记录理由。未核实留空。 |
| `answer-key.json` | 四组结果和盲评卡号的对照；完成盲评后再查看。 |

完成后运行：

```bash
news2douyin-review score review-2026-11-15 --ratings review-2026-11-15/ratings.csv
```

每组都列出已评、未评、标为值得读的数量，以及依据人工分组确认的重复席位。覆盖分母是本次盲评材料里已标为重要的独立进展。网页只记录值得读和事实分组；若编辑同时希望评估深度研究潜力等指标，可填写原始 `review.csv` 的可选列。

榜外样本默认取 20 条，可用 `--outside 0..100` 调整。抽样范围是四组清单的所有代表条目以外，包含可能作为其他条目关联材料出现的报道。归并统计只涵盖选席时实际考察的候选；同一期全网的潜在相关报道可能更多。请在未参与规则开发的日期检验，对照人工确认的误合并、缺失进展和重复席位。该命令写入本地对照目录，线上已发布的工作流继续使用原排名。
