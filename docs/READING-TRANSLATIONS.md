# 按需译读与语言标签

翻译用于帮助阅读已保存的文字，不替换原文、资料快照或引用依据。只有用户点击后才排入已有执行队列；浏览、筛选和展开来源不会批量翻译或自动访问报道网页。

## 语言字段的含义

新闻材料优先显示该材料／固定版本已经保存的 `language` 字段，并注明来自字段；缺少可靠字段时显示未知。日文假名、韩文等只能提示“可能”，不把脚本推测伪装成来源给出的语言。拉丁字母无法单独区分英语、法语、波兰语等，因此不自动判英语。

官方 Events 与 Mentions 本身没有可直接作为原报道语言的字段。翻译流名称不等于报道语种，中文CAMEO名称也不等于原新闻为中文。官方事件条目的翻译范围是已存主体、对象、行为与地点，用于辅助理解自动编码线索，不声称已经取得或翻译新闻全文。

## 执行与缓存

复用已有OpenAI兼容模型配置 `OPENAI_BASE_URL`、`OPENAI_API_KEY`、`MODEL`，不需要新增外部翻译服务或另一套账号。模型不可用时明确显示失败和检查配置提示，原文保留，不用规则文字冒充机器译文。

复用现有 `TaskWorker`、任务租约、取消和恢复机制。HTTP提交只读取本地资料并保存短事务，不等待模型响应。翻译可能排在已有采集、脚本或视频任务之后，排队状态与执行状态分别显示；可关闭页面，稍后再次点击读取结果。

译读对象在点击时冻结。标题最多1000字符，正文最多6000字符；超出显示截断提示。官方事件元数据同样最多6000字符。缓存身份包括资料、版本、范围、目标语与输入内容哈希。历史版本使用该版本的不可变文字；原文变更时创建不同缓存；同一输入重复点击复用一个任务。只翻译标题和翻译正文分别缓存。

成功结果只保存在 `ReadingTranslation`，不会写回Article、ArticleVersion、TopicSource、Event或证据判断。模型配置在提交后改变时，原任务明确失败；在原页面点击重试以使用当前配置。失败任务默认不自动反复提交，明确重试创建一个新的任务尝试。输入校验、缓存写入与结果写入不跨模型网络请求持有数据库事务。

## API

```json
POST /api/translations
{
  "kind": "article",
  "key": "已有article_key",
  "target": "zh-CN",
  "scope": "title",
  "revision": 1,
  "retry": false
}
```

- `kind`：`article`、`gdelt_event`或`topic_source`。`topic_source`的key为已存资料快照ID。
- `scope`：`title`、`content`或`document`（默认）。官方事件快照返回范围`event_metadata`。
- `revision`：可选正整数，仅用于article；不传时翻译点击时保存的当前材料。资料快照本身已固定版本，不再另传revision。
- `retry`：失败／取消后明确重试时传true；相同活动或成功输入仍复用原任务。
- 只接受保存对象标识，不接受客户端任意 `text` 或模型提示词。
- `GET /api/translations/{id}` 返回 `status`、`original`、`translated_text`、语言说明、`truncated`、`task_id`和可读错误。

模型只接收系统翻译要求与JSON封装的文字；其中外部命令是待译数据，不开启工具或执行链接。网页显示结果应使用textContent，避免译文或原文HTML成为可执行页面。
