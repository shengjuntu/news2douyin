# 接入现有NewsNow数据

本版直接调用已部署的NewsNow，不移植各平台爬虫，不依赖公共演示站。服务地址可在“运行管理 → 定向采集策略”选择NewsNow后配置。配套配置为`configs/v7/profiles/newsnow_cn.yaml`，预填用户提供的`http://192.168.0.234:4444`，可以改为部署机实际可达地址。

仅使用`GET /api/s?id=<source>`，读取JSON；不请求Markdown、RSS、MCP或原始报道网页。HTTP200的SPA页面、错误JSON、错误来源ID和无效items均不能视为采集成功。部分父来源的已知返回别名由代码明确处理，未知不匹配仍失败。

## 最短操作路径

1. 在采集策略新建或编辑，新闻源选择NewsNow。
2. 确认服务地址，勾选需要的榜单/快讯来源。高级项可填写自定义来源ID。
3. 点击策略试跑，核对逐源结果及筛选原因。试跑保存运行与原档，不写Article。
4. 正式采集后在雷达的中文平台关注视图查看归并议题、榜单位置和候选来源事件；新闻库仍保留标题/摘要线索。形成选题后先补原文或深入研究。
5. 持续采集使用原有定时计划。可将更新快慢不同的来源拆成不同策略；频率由实际源更新情况与服务负载决定，重复读缓存不会制造新文章版本。

默认规则筛选、空类别与关键词，不启动财经LLM筛选；用户明确设置的排除词、来源名单和相关性条件仍生效。默认1200条在线候选足以容纳参考清单35源各30条；数字不是承诺每轮固定产出。先遍历所选来源，再轮转分配在线条数；不会因为前面的源先填满max_items就直接跳过尾源。总时间/字节预算耗尽时，后源标为未尝试。

## 原始资料与在线线索

- 每源完整响应保存在`storage_root/newsnow/snapshots/<sha256>.json`；错误HTML等非JSON响应使用`.body`。相同响应字节复用一份文件，已存在文件哈希不一致时拒绝覆盖。
- 每轮`newsnow-snapshots.json`保存来源、观察时间、响应状态、快照报告时间、哈希和原档相对引用；没有网络响应时保留失败状态，不制造空原档。
- `Article`保存可选题的标题/来源摘要/链接和小型追溯信息；`extra.hover`是摘要，不能冒充全文。股票榜如xueqiu只保留原始观察，不写成新闻Article。
- 新线索默认不逐条创建本地Event，也不自动排入模型抽取。选题、译读、补材与深研究继续现有工作台；以后同URL取得真实正文，可以升级原身份并进入既有本地事件流程。
- 不同来源命中已有真实报道时，NewsNow不会覆盖正文或来源署名。规范化URL去重，未改变标题/摘要/真实发布时间的重复观察不增加ArticleVersion。
- 榜单变化保存在快照中，不随每轮排名变化改写文章版本；文章页面的列表位置是该版本收录时位置，不是当前官方名次。

原始响应与在线条数截断分开，未进入在线候选的条目仍在原档。现有API榜单本身可能只有前30条，不在返回列表不代表零关注。0.29.0在后台从正式采集快照生成具体议题、关注位置指标和GDELT候选关联；完整公式、缓存与缺测处理、有界匹配范围见[关注议题说明](ATTENTION.md)。它们是线索与代理指标，不能当作平台真实阅读量或已核实的事件身份。

## 三种时间

| 字段 | 含义 |
| --- | --- |
| published_at | 仅使用条目给出的有效时间。缺失保持未知，不拿快照时间代填 |
| snapshot_reported_at | NewsNow返回updatedTime所报告的时间；不能一律当作真实上游重新抓取时间 |
| observed_at / fetched_at | 本应用本轮读到响应的时间 |

处理毫秒/秒、RFC2822、带时区ISO、无时区中文站日期时间、纯日期及不补零日期。明确的无时区字段按来源约定使用北京时间，并保存时区假设。纯日期保留日精度，UI不展示伪造的00:00时刻。保留上游原始字段，未知/坏日期不凑时间。

## 诊断与恢复

试跑、任务诊断与运行详情显示逐源成功、成功空榜、失败及未尝试。全源不可读时任务明确失败；合法空榜独立记账，不把它和断网混在一起。部分失败时其它成功源仍可入库，失败原因可见。

HTTP在事务外执行。任务raw/filtered阶段冻结到带SHA256的文件，SQL checkpoint只保存小型指针及诊断；恢复后使用已冻结输入，不重新抓取后再冒充同一轮。缺文件或哈希损坏时明确失败，不静默换输入。另测了报告已保存但raw尚未冻结的停止窗口，恢复可安全重新观测。

备份/迁移应保留完整storage_root，不能只备份PG后删除运行目录；这些冻结文件是任务重试输入的一部分。

默认每源连接5秒、读取15秒，整轮预算180秒；单响应最大2MiB，整轮响应最大32MiB。可配置`newsnow_connect_timeout`、`newsnow_read_timeout`、`newsnow_total_timeout`及在上限内的`newsnow_max_response_bytes`。网络失败不回显原始异常凭据；原始错误响应保留在归档，网页仅显示可读诊断。

## 在部署机实测

本轮开发环境无法连接用户私网地址，没有部署或修改现场。以下命令应在news2douyin实际运行的主机/容器执行：

```bash
python tools/probe_newsnow.py \
  --base-url http://192.168.0.234:4444 \
  --sources zhihu,cls,douyin \
  --output newsnow-probe.json
```

默认只探测少量来源；明确传`--sources all`才探测默认全清单。该工具不写业务库。退出码0成功、2部分失败、3全源失败、4成功但全空、1配置或运行错误。不要拿`/api`的506响应当本版采集接口是否可用的判断，实际请求的是`/api/s?id=`。

容器内localhost指容器自身，地址须从news2douyin所在环境可达。上传方案中的35可用/795条等为当时现场样本，不作为固定验收值；应核对本轮实际逐源结果。
