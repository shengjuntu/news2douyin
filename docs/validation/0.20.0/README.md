## 复现

```bash
python -m pip install '.[dev,research]' falkordblite==0.11.0
pytest -q
python tools/check_content_upgrade.py /path/to/news2douyin-0.19.0-py3-none-any.whl
```

浏览器验证另需 Node、playwright-core，以及可用 Chromium。设置 `N2D_QA_CHROMIUM` 为可执行文件；如依赖不在默认目录，设置 `NODE_PATH`。运行：

```bash
python tools/check_workbench_live.py /tmp/n2d-ui-check
```

该脚本使用独立临时数据库，输出目录仅供内部截图与服务日志；不会接入用户数据库。研究测试端点只在这个验证脚本中注册，正式应用不存在这些端点。

## 诊断与限度

一次早期浏览器试跑在工作目录的测试 SQLite 文件中出现重复索引结构异常，来源尚未确定；没有修复或迁移该损坏测试库。之后使用全新隔离临时库完整重跑通过；再次复跑并执行 SQLite integrity_check 为 ok，在关闭服务器后清理。该观察保留于验证记录，不能视为已定位或已修复生产数据库问题。

模型抽取质量、新闻重要度排序的真实标注评测、跨语言同名消歧、大规模吞吐与长期运行稳定性不在这次功能验收范围。算法的具体边界见 `../../CORE-WORKFLOW.md`。先备份原数据库，并在测试实例验证自己的模型、来源和 RunDesk 连接。
