# 研究检索职责与升级：0.14.0

日期：2026-10-13。配套 RunDesk 0.48.0，无需修改 RunDesk 或重建其 Codex 镜像。

## 一条研究外部搜索路径

| 能力 | 负责方 | 行为 |
| --- | --- | --- |
| 日常新闻采集、定时关键词采集、专题材料补充 | news2douyin 采集模块 | 继续使用已配置的新闻源与采集 API，独立于 Agent 研究 |
| 本地新闻库检索 | news2douyin 研究 MCP | 查询已经入库的标题和正文，不向外部搜索服务发请求 |
| 外部研究搜索 | RunDesk 中的 Codex / Exa MCP | 按研究票据执行一次指定搜索，将真实结果交回新闻服务 |
| 预算、线索记录、原文证据、判断与报告 | news2douyin 研究 MCP | 保存可回查研究数据；原文读取会访问指定 URL，但不是再搜索一次 |

研究模块已删除直接调用 WorldNewsAPI/Tavily 的适配器。研究设置不再提供第二套搜索服务或搜索 API Key；旧研究密钥保留在原设置中但不参与请求，采集模块的账号配置不变。

## MCP 调用约定

保留现有 7 个工具名称，应用无需更换 MCP 地址或 Token。

1. `research_get_case` 读取已有材料和 `search_policy`。先复用资料；旧报告里的 HTTP 400 不代表本轮 Exa 已失败。
2. `research_search(scope=library)` 只查询本地库。它不增加 `search_count`；`max_searches` 现在只用于外部查询。原有本地匹配方式和最多 12 条结果保持不变。
3. `research_search(scope=web)` 默认只预留一次外部预算，返回 `ticket`、`server=exa`、`tool=web_search_exa`、查询和时间范围。`server_side_search_performed=false` 表示新闻服务没有执行外网搜索。
4. Codex 读取 Exa 工具的实际参数 schema，执行一次搜索。不要将票据的全部字段原样传给 Exa；`ticket` 是新闻服务的记录编号。
5. `research_record_search` 回存真实结果或错误。同一票据的相同回存幂等，不同结果不可覆盖。结果仍标为 Agent 转交、未独立验证的线索。
6. 用 `research_read_source` 获取可引用原文，再保存判断与报告。

同一轮内，相同关键词（忽略首尾空白）的默认 web scope 和显式 web scope 复用同一票据；并发申请只占一次预算。票据已回存时 `needs_external_call=false`，直接使用结果，不再搜索。升级前已发出的 Exa 票据也可复用。

票据去重不是对所有外部工具的网络代理。Codex 保持完整访问权限；不通过权限设置强行禁用 Agent-Reach、原生搜索等其他工具。当前研究任务的提示、MCP 描述和 Skill 明确要求只用选定 Exa 路径，不能据此宣称已实现进程级硬配额或外部搜索的全局 exactly-once 保证。外部调用结果不明时应核对轨迹，不能盲目再次请求。

## 错误与迁移

- HTTP 400 表示请求被拒绝，不足以推断凭据问题或额度耗尽。记录原始错误；尚有研究预算时可以修正查询再申请新票据。
- 只有研究服务明确提示外部预算耗尽，才按这一原因结束检索；认证、网络、参数、任务迁移应分别说明。
- 设置中的旧 WorldNewsAPI/Tavily/Wigolo 路径会自动迁移为 RunDesk / Exa。历史运行环境、来源、报告和旧密钥保留。
- 旧轮次不被悄悄改写。旧路径的 web 查询返回明确的重启指导，即使同一查询曾缓存 400，也不会继续返回旧 400。
- 旧轮次仍可查本地库、读取已有证据、保存判断和 partial 报告。停止旧轮次并在原课题继续研究后，新轮次使用 Exa。
- Docker 和本机模式提交模型前都检查研究 MCP 的 7 个工具和 Exa；缺失时提前报配置问题，不回退新闻采集 API。

## 升级

1. 在原课题停止旧研究，确认已停止。
2. 停止 news2douyin 服务，在原 Python 环境中安装包内 wheel：

   ```bash
   python -m pip install --upgrade ./release-0.14.0/news2douyin-0.14.0-py3-none-any.whl
   ```

3. 用原启动参数、原数据库和数据目录重启服务，刷新网页。若新闻服务本身在容器里，更新的是该服务容器；不需要重建 RunDesk 的 Codex 镜像。
4. 在研究设置点击“连接并配置环境”，然后检查连接。保留已有 Exa 自定义地址及认证；不需要把采集账号再填到研究设置。
5. 回到原课题点击“启动环境并继续研究”。新轮次的实际检索服务应显示 RunDesk MCP / exa。

软件包中的研究 Skill 已更新。连接时仍保留已有自定义 Skill，不覆盖管理员编辑；新轮次的提交提示和 MCP 工具描述始终携带新的单一路径约定。需要更新自定义 Skill 时，应保留自己的附加要求并对齐上述约定。
