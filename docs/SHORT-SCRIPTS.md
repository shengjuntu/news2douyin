# 短脚本与轻量补材 · 0.15.0

## 用户操作

在「每日选题」勾选新闻，选择生成方式、脚本语言与目标时长。

| 方式 | 输入与结果 | 执行方 |
| --- | --- | --- |
| 基础摘录稿 | 每条新闻一稿，保留原文语言，不翻译、不搜索 | news2douyin |
| AI 初稿 | 每条新闻一稿，仅用所选资料；可将英文新闻写成中文口播 | 已配置的兼容模型服务 |
| 轻量补材并生成 | 最多 6 条相关报道合并一稿，按需补背景、核对冲突、查找配图 | 现有 RunDesk / Codex 实例 |

AI 与轻量模式支持简体中文、English、日本語，目标时长为 30 / 60 / 90 / 120 / 180 秒。AI 初稿也可选择保留原文语言。时长是篇幅目标，不是音频时长保证；翻译与事实仍需审核。

轻量模式允许填写讲述角度，并关闭配图搜索。提交后进入 `/short-scripts/{case_id}`，可关闭页面；news2douyin 与 RunDesk 服务应保持运行。稍后从脚本工作台的「轻量补材与短稿任务」找回。任务显示搜索/读取计数、停止、失败后继续、证据入口和草稿入口。移出每日选题不取消独立的轻量任务；在任务页停止。

切换现有每日稿件的输出语言或时长会生成新稿，旧稿及审核历史保留。相同要求复用结果。轻量任务也不覆盖已有稿件；交付后在脚本工作台修改，如需重新补材则新建任务。

## 轻量范围与搜索归属

复用研究执行器、Docker 环境准备、Exa 配置、MCP 回调、任务回执和恢复流程，不新增搜索服务、凭据或 Docker 镜像。

- 所选新闻先保存原文快照。优先复用已有资料，必要时查本地新闻库。
- 一轮最多预留 3 次外部搜索、6 次新增正文读取；本地检索和读取已有快照不消耗外部搜索次数。
- 5 分钟是补材工具预算：超时拒绝新增检索/读取，仍允许保存已有依据的短稿。这不是墙钟硬中断，也不包含环境准备耗时或保证整项任务五分钟完成。
- 外部搜索统一为 `research_search(web)` 发票据 → Codex 调用 Exa `web_search_exa` → `research_record_search` 回存真实结果。
- 结果摘要仅为线索；需要 `research_read_source` 读取原文，再保存带精确摘录的判断。正文抓取和图片下载是检索结果的读取，不是第二个搜索提供方。
- 优先停止在素材足够的位置；不强求用完预算，不强行把无关报道合成同一事件，转载不等于独立证实。
- 相同查询票据在同一轮复用。Codex 仍在完整访问模式；票据与提示词约束不等于全局网络代理或跨服务硬配额。

语言作为任务输入固定保存，资料可以为英文而输出为中文。原始摘录不翻译、不被生成稿覆盖。普通事件脚本生成也新增了语言选项；无需模型的提纲继续保留原文。

## 配图

必要时由同一 Exa 流程查找图片所在的报道、机构或公开素材页面。HTML 读取器从实际页面的 `og:image`、`twitter:image` 与 `img` 中提取候选；模型必须使用这些已观察到的链接，不能自行编造图片 URL。

最多选择 4 张配图，并行获取、检查后保存到 news2douyin 的运行目录。沿用公网地址解析/逐次重定向校验和 4 MiB 单文件上限；只接收 JPEG、PNG、WebP，限制尺寸及总像素。图片组件缺失、链接不可访问、反盗链或格式检查失败时，保留来源页面和缺口，文字稿仍可交付。

脚本编辑页显示本地图片预览、下载、来源页面与授权状态。当前统一标记「授权尚未核实」，页面图片不保证就是事件现场。候选图片不会自动用于成片。审核后导出制作包时，包含 `images/` 图片、`assets_manifest.json` 的原始/最终 URL、哈希、尺寸、读取时间和授权状态。使用者核对用途后再交给视频制作模块选择分镜配图。

这不是专用图库搜索或图片授权服务；遇到页面无配图、动态加载或无法访问时允许空结果。深度报告到长视频的完整工作流不属于此版本。

## API 与存储

`POST /api/short-scripts` 接收：

```json
{
  "article_keys": ["article_1", "article_2"],
  "output_language": "zh-CN",
  "duration_sec": 60,
  "find_images": true,
  "angle": "面向普通观众解释此次变化",
  "idempotency_key": "调用方生成且同次重试保持不变的编号"
}
```

返回持久化 `case_id`、当前状态、配置、计数，以及交付后的 `package_key` / `script_url`。同编号同内容重试复用任务，编号对应其他内容时报错。`GET /api/short-scripts` 为最近任务；`GET /api/short-scripts/{case_id}` 为摘要；`POST /api/short-scripts/{case_id}/start` 显式继续未交付任务。停止和详细原文/证据复用 `/api/research/cases/{case_id}` 下现有接口。

MCP 新增第 8 个工具 `research_save_short_script`：仅对轻量任务有效，接收标题、分段 `text/kind/claim_ids/visual/assets`、画面备注、编辑备注、缺口和候选图片。服务端校验课题归属、精确原文引用链、判断类型和实际页面图片链接，原子保存素材报告和版本化短稿。事实段不得引用推断/未证实判断充作事实；语义是否准确仍须人工审核。保存到脚本工作台后，逐段引用和事实/分析约束继续保留。

每日脚本 API 与事件生成 `options` 新增 `output_language`；每日生成也支持 `duration_sec`。`ScriptDocument` 和导出清单保存输出语言，英文分析段使用 `Analysis: ` 前缀。旧资料表不改写，只新增 `ShortScriptBrief` 表；旧版 JSON 缺字段时沿用原行为。

## 升级与验收

1. 停止 news2douyin，备份原数据库、运行目录及配置；在原 Python 环境安装本包，保持原数据库和 storage_root 路径。
2. 安装 `news2douyin[research]`，其中包含网页/PDF 与图片读取依赖。源码安装：`python -m pip install -U '.[research]'`。离线部署需同时准备依赖 wheel。
3. 重启 news2douyin，打开「研究助手设置」连接/检查。应发现 8 个 news2douyin MCP 工具和 Exa。若旧会话还缓存工具列表，开启新任务。原应用绑定、凭据与已有证据保留。
4. RunDesk 继续使用 0.48.0；已有 Exa / Codex Docker 环境可复用，无需因本功能重新构建镜像。图片由 news2douyin 服务下载并保存，其宿主机也需要能访问图片来源。
5. 选一条英文新闻，选「AI 初稿 → 简体中文 → 60 秒」，检查口播语言及英文原文快照。
6. 选 2–3 条同一事件的新闻，选「轻量补材并生成」，启用配图；关闭页面后从任务列表返回，检查计数、来源、缺口、短稿和图片。完成审核后导出，核对图片文件及来源清单。

验证记录见 `docs/validation/0.15.0/`。自动测试使用模型、搜索和图片响应替身；两服务联调使用真实 RunDesk/news2douyin HTTP 与 MCP，Docker CLI/Codex/搜索为替身。真实模型成稿质量、Exa 搜索覆盖、图片网站可达性和浏览器视觉效果需在部署环境验收。依赖 FFmpeg/字体的渲染测试在当前环境跳过。
