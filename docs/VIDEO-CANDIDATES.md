# 视频候选

在事件雷达切换到「视频候选」，选择日期后生成该期清单。系统从当日截止时可见的共同候选层另选最多 100 条。每期可单独下载 Markdown，再从里面挑十条和决定拍哪条。今日可随到随更新，历史日期可按已有采集材料生成。

视频候选优先挑有具体当事人或生活角色、能说清发生了什么、能说明与日常生活有什么联系的材料。卡片展示可核对的入选线索和报道链接。分数用于该期排序，供编辑判断是否值得做成视频。

同一件具体事情有后续报道时，可以查看有出处的前期线索。点击「跟踪故事」，会把所选标题带到新建焦点的描述里。核对范围并保存后，焦点会持续归集新材料。

视频候选与每日精选各有日期、版本、生成状态和下载入口。按需生成是默认设置。可将 `NEWS2DOUYIN_VIDEO_DIGEST_AUTOMATIC=1` 写进运行配置，启用随日报节奏的后台生成。`NEWS2DOUYIN_DIGEST_ENABLED` 是两类日报任务的总开关。
