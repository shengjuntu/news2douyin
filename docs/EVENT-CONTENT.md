# 全球事件线索的报道内容

## 展示的是什么

`OfficialEvent`保存GDELT自动编码的主体、行为、地点和日期；它本身不提供可直接阅读的新闻标题。`OfficialMention`把文档关联到事件，也不包含原文。因此卡片不能只把这几个字段连起来冒充新闻内容。

0.30.0的内容层从关联文档取得标题与摘要，主卡显示“相关报道”，编码关系放在次要位置。一篇报道可能讲多个事件，不能把整篇报道的摘要当作某一个编码事件的核实描述，也不能直接把Mentions字符偏移套到当前网页切片。

## 本地优先与只读列表

当前页最多100条事件，每条取官方首次来源URL，并从最多12条近期已索引Mentions中选择3条。近期候选按已有事件／时间索引读取，避免热点事件先排序全部历史提及；同一时间戳的记录不承诺全库置信度顺序。候选URL最多400个，批量通过`ArticleIdentity`的固定长度URL身份定位`Article`，读取标题、前1200字符正文和少量元数据。没有对长URL列做OR扫描，也不加载全部ArticleVersion或原始GKG记录。

详情中的来源列表同样先按时间索引读取最多31条近期提及，再在这些候选内按置信度展示最多30条；它不是全历史最高置信排名。卡片仍从其中最近12条候选选择最多3份预览，接口提供范围说明。

已保存的真实标题优先于远程缓存。没有本地内容时使用`SourcePreview`；本地只有标题而缓存有摘要时，只在标题经过Unicode、大小写和空白归一后完全相容时借用该摘要。否认、数量或词项已经变化的标题不会拼上旧版本摘要。

列表、详情与`GET /api/gdelt/content/cards?event_ids=...`只读取SQL。批量刷新最多30条指定事件，不重算来源覆盖总量，不写任务、不联网。缺内容、只有标题、抓取中、失败和不可用保持不同状态。

## 后台如何补充

`SourcePreview`按规范化URL身份保存标题、摘录、语种、来源、内容哈希和观察时间；`SourcePreviewJob`保存独立队列、租约、退避和错误。共享来源文档或追踪参数别名不会重复创建任务。

默认后台每轮只处理一个来源，并有界发现最近7天中最新60条事件；自动活动队列上限200，页面显式请求优先，总活动请求上限1000。这是有限补材预算，不表示自动抓取所有历史新闻。页面自身不自动POST；用户点击“补充本页报道”才提交该页请求。

`POST /api/gdelt/content/enrich`接受最多30个已有事件编号，不接受任意URL。后台从这些事件及其有限Mentions中取来源，先尝试本地资料，再安全抓取。网络期间关闭SQL会话。任务使用进程所有权、租约续期与发布栅栏，旧任务不能覆盖新结果。已有标题缺摘要只自动补一次；完全缺内容最多自动尝试三次，之后需明确重试。显式重试不会修改原始接收游标或删除资料。

## 来源抽取与传输边界

HTML优先采用OG／Twitter标题、H1和HTML标题，摘要优先来源描述，再取正文首段。它们是来源文字摘录，不是生成的事件总结。脚本、导航、错误壳、验证码和无标题页面不能充当新闻；URL片段也不转换成标题。语言使用页面声明及保守文字判断，不能依据国家或CAMEO标签判定报道语种。

预览复用`research.sources.safe_fetch`，保留公网标准端口、所有DNS地址校验、固定连接IP、HTTPS域名验证及每跳重定向校验。新预览请求启用35秒总预算与512KiB解码上限，覆盖DNS等待、重定向、响应头和慢速正文；最多两条仍在等待的DNS解析，不能因超时无限创建后台线程。旧调用未指定预算时保持既有研究读取行为。

来源返回限制页或无法读取时，页面显示错误与来源链接。抓取成功仅表示拿到了相关报道的标题／摘录，不证明编码正确、内容真实或报道覆盖完整。

## 翻译、选题与研究

卡片的中文译读使用`source_preview`类型，以URL身份定位已保存预览或本地报道，翻译当前可见的标题和有限摘录；原文和翻译输入按内容哈希固定。点击按钮后才创建翻译任务，不因浏览卡片自动调用模型。

形成选题保留事件元数据，并冻结相关报道的标题、摘录、来源与内容哈希。摘要资料标为`search_snippet`，仍受原文不足的写稿保护；即使本地Article另有长正文，该预览快照也不因此被当作已经完成核查的全文。旧任务快照不随之后补材或标题更新而改变。

## 接口

| 接口 | 行为 |
| --- | --- |
| 既有事件列表与详情 | 返回真实报道显示标题、摘要、语种、内容状态与结构化辅助标签 |
| `POST /api/gdelt/content/enrich` | 同源请求排队补充已有事件的关联报道 |
| `GET /api/gdelt/content/cards` | 最多30事件的只读内容刷新，保留原卡来源数等字段 |
| `GET /api/gdelt/content/status` | 有界队列与后台状态，不扫描全部历史缓存 |
| 既有翻译与形成选题接口 | 使用真实可见报道文本及冻结快照 |
