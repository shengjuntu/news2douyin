# 世界态势

从主导航「事件雷达 → 世界态势」打开 `/radar/world`。地图、筛选和列表使用本地数据。默认看最近三个北京时间日，含截至日期，可选当天或近七天。

| 视图 | 怎么读 |
| --- | --- |
| 事件进展 | 查看有出处的已核时间线、整理事件和带可读报道的 GDELT 编码线索。精确地图点来自 GDELT ActionGeo 自动地理编码。已核行动地如果只有国家精度，会聚合至国家。位置待核的来源在列表可见。 |
| 报道升温 | 查看配置地区和主题的 GKG 日度指标、归档覆盖及异常状态。现有指数用平均负面词比例乘以报道量的对数。过去 30 天至少 14 个有效日，且已结束日期覆盖达到 95%，才与基线比较。数据不足显示待核或缺批次。今天的全球视图另有原热点最近两个 36 小时窗口的持续关注卡。 |
| 商品研究线索 | 从事件原文及采集索引找有实际范围的政策、矿厂运行、供需库存、运输中断等线索。初版识别铜、天然气，也显示承运商品待查的运输线索。卡片给出候选传导、最先要查的证据和适用指标。 |

历史日期按当前存有的材料、事件和地点标注回看。后补资料和更正可能改变历史结果。事件和商品页都用限量样本；列表提示达到取样上限。来源和资料覆盖情况影响可见范围。

## 市场研究

在商品线索或已有事件详情点「研究市场影响」。确认页列出当前起点和依据。点「发起研究」后才创建或接续同一依据版本的研究任务。RunDesk 使用既有研究连接，任务可回到研究进度，报告仍按既有方式导出。

查询市场数据沿用 `NEWS2DOUYIN_TRADE_VIEW_BASE_URL`、`NEWS2DOUYIN_TRADE_VIEW_API_KEY`，TradeView 侧启用既有访问密钥与 PriceDB 连接。商品研究 MCP 可以查原生序列目录、单位和频率及按统计期提供的原始观测。PriceDB 目前提供最新修订值。预估证据不足、商品未知或行情缺口会留给研究核实。

## 现有入口和配置

- `/radar` 仍打开每日精选。全球事件线索、已整理事件和中文平台关注在导航保留。
- 热点旧页、地缘报道日线和采集候选在「来源与回查」。已整理事件的国家圆图可从「证据工具」打开。
- 地缘报道后台沿用 `NEWS2DOUYIN_GEORISK_ENABLED=1` 及已有归档目录。未启用或缺归档时，地图仍可打开事件进展。
