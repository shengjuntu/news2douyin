# 世界态势

从主导航「事件雷达 → 世界态势」打开 `/radar/world`。地图、筛选和列表使用本地数据。默认看最近三个北京时间日，含截至日期，可选当天或近七天。

| 视图 | 怎么读 |
| --- | --- |
| 事件进展 | 查看有出处的已核时间线、整理事件和带可读报道的 GDELT 编码线索。精确地图点来自 GDELT ActionGeo 自动地理编码。已核行动地如果只有国家精度，会聚合至国家。位置待核的来源在列表可见。 |
| 报道升温 | 查看配置地区和主题的 GKG 日度指标、归档覆盖及异常状态。现有指数用平均负面词比例乘以报道量的对数。过去 30 天至少 14 个有效日，且已结束日期覆盖达到 95%，才与基线比较。数据不足显示待核或缺批次。今天的全球视图另有原热点最近两个 36 小时窗口的持续关注卡。 |
| 商品研究线索 | 从事件原文及采集索引找有实际范围的政策、矿厂运行、供需库存、运输中断等线索。初版识别铜、天然气，也显示承运商品待查的运输线索。卡片给出候选传导、最先要查的证据和适用指标。 |

历史日期按当前存有的材料、事件和地点标注回看。后补资料和更正可能改变历史结果。商品研究线索按窗口取限量样本。事件进展优先读取后台索引，页面标明正在展示的范围。来源和资料覆盖情况影响可见范围。

## 跨日期的议题

进入「事件进展」，用日期、国家、类别找窗口内有进展的议题。列表每页 20 个，地图对应当前页。卡片上的报道数按规范化 URL 去重，进展数按行动计数。点议题时间线可看全部已整理日期，每页 40 项。一个跨国议题可以出现在多个国家筛选中。「收录」是系统观测时间，「发生」取已核行动日期或 GDELT 编码日期。

议题通过本地事件编号、明确的欧盟法规编号、带行动的具名风暴等线索归组。设施规则覆盖苏伊士运河、巴拿马运河、鹿特丹港、刻赤大桥及埃斯孔迪达铜矿。设施、行动国家、干扰原因和 ISO 周同时匹配才能组成一期，因此跨周的同一中断可能分开。归组用于阅读；是否存在传导关系仍需检查证据。可从具体进展手动发起市场影响研究。

## 索引与升级

0.61.0 启动时在业务库新增五张派生表，分别保存议题、进展、分类、来源引用和后台游标。保留原有 PostgreSQL 数据库、存储目录和配置即可。历史整理在服务启动后进行。索引保留短摘录及可用的原始版本链接，单条行动在页面展示最多 16 个来源版本。

后台分批读取本地事件、已核的具体行动，以及业务库里带可读报道的 GDELT 官方事件。原始归档中新下载的批次需先进入业务侧事件和报道索引。实时线索和历史补扫各有游标，一批成功提交后才推进。未匹配到可用材料的记录计入已扫描数。完成一轮后隔六小时开始下一轮，可补进迟到的报道，也能反映旧行动的修订。

`NEWS2DOUYIN_WORLD_INDEX_ENABLED` 默认为 1，设为 0 可暂停后台整理。每条输入流的单批记录数由 `NEWS2DOUYIN_WORLD_INDEX_BATCH_SIZE` 设置，默认 32，可选 1 至 200。配置在启动进程的环境中生效。首次整理期间可以使用已生成的议题；所选窗口尚无索引结果时，可先浏览页面明确标注的近期样本。

## 市场研究

在商品线索或已有事件详情点「研究市场影响」。确认页列出当前起点和依据。点「发起研究」后才创建或接续同一依据版本的研究任务。RunDesk 使用既有研究连接，任务可回到研究进度，报告仍按既有方式导出。

查询市场数据沿用 `NEWS2DOUYIN_TRADE_VIEW_BASE_URL`、`NEWS2DOUYIN_TRADE_VIEW_API_KEY`，TradeView 侧启用既有访问密钥与 PriceDB 连接。商品研究 MCP 可以查原生序列目录、单位和频率及按统计期提供的原始观测。PriceDB 目前提供最新修订值。预估证据不足、商品未知或行情缺口会留给研究核实。

## 现有入口和配置

- `/radar` 仍打开每日精选。全球事件线索、已整理事件和中文平台关注在导航保留。
- 热点旧页、地缘报道日线和采集候选在「来源与回查」。已整理事件的国家圆图可从「证据工具」打开。
- 地缘报道后台沿用 `NEWS2DOUYIN_GEORISK_ENABLED=1` 及已有归档目录。未启用或缺归档时，地图仍可打开事件进展。
