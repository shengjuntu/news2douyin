# 跑通一天：从新闻到成片

## 第一次启动

解压后进入项目根目录。使用 Python 3.10 或以上，在虚拟环境中安装并启动：

```bash
pip install -e ".[video,voice-offline]"
news2douyin-server --host 127.0.0.1 --port 18080
```

浏览器打开 `http://127.0.0.1:18080`。默认数据库和运行目录在当前目录的 `runs_v7`。以后从同一目录启动；也可用 `--db-url` 和 `--storage-root` 明确指定原路径。关闭网页不会停止任务，关闭服务会暂停处理。

## 先验证操作流程

1. 打开“采集策略”，新增策略，新闻源选“演示数据”，保存。
2. 回“每日选题”，选今天和这个策略，点击采集。任务完成后点击“选择本次新闻”。
3. 勾选一条，选“基础摘录稿”，生成。到任务页等待完成，再打开草稿。
4. 编辑标题、口播和画面提示，核对来源。提交审核并完成来源、措辞检查后，通过审核。
5. 点击制作视频，选择新闻简报模板、快速预览规格和离线配音。可先用信息卡，无需上传图片。
6. 检查环境、预览画面、提交制作。到作品库播放，下载 MP4 或完整制作包。

演示数据和机械配音用于验证安装与操作。视频页如果提示缺少 FFmpeg、FFprobe 或中文字体，按该页提示配置；可用 `NEWS2DOUYIN_VIDEO_FONT` 指向本机中文字体文件。不要把“已经安装 Python 包”视为系统编码环境已经齐全。

## 换成真实新闻

复制 `.env.example` 为 `.env`，填写新闻账户的 `API_KEY` 后重启服务。已有系统环境变量优先于 `.env`；可用 `NEWS2DOUYIN_ENV_FILE` 指向指定配置文件。

在采集策略中选择 `worldnewsapi`，设置国家、语言、关注词及来源范围。选择“热门榜单”获取榜单，选择“主动关键词检索”向新闻源提交检索词。先试跑，查看取得条数、过滤原因和样本，再用于每日采集或配置自动采集时间。是否能查询指定日期、语言和历史范围，取决于新闻源及账户权限。

没有新闻时先看采集诊断：上游没有结果、过滤条件过窄、重复抓取与请求失败含义不同。新闻库可分别按报道发布时间、采集时间查询；“事件发生时间”需在事件专题中结合证据整理。

## 接入 AI 中文稿

在 `.env` 中设置正在运行的兼容模型服务，例如：

```dotenv
OPENAI_BASE_URL=http://127.0.0.1:19993/v1
OPENAI_API_KEY=vllm
MODEL=你的实际模型名称
```

上面的地址和密钥是本地服务示例，需与实际部署匹配；模型名称不要直接照抄。`127.0.0.1` 指运行 news2douyin 服务的那台机器，模型在另一台机器时应填写它可访问的地址。修改配置后重启服务。

每日选题选择“AI 中文初稿”提交，等待后台任务。若请求失败，检查模型服务地址、名称、鉴权以及响应格式；任务页不会回显密钥。输入固定在提交时，切换模型地址或名称后，应恢复原配置重试，或将未成稿的选题移出、重新选择再提交。

日常单条报道可以直接写初稿。需要深度复盘时，到“事件专题”收录多篇报道、整理并核对进展节点，再生成带逐段引用的脚本。审核后制作视频，两种稿件最终都保存在脚本工作台和作品库中。

## 第二天接着用

确认服务和定时采集在运行；打开每日选题查看今天的新闻，通常选择 1–3 条。昨日稿件在脚本工作台，成片在作品库，新闻原文在新闻库。切换日期不会删除选择或稿件，归档作品也不会删除媒体文件。
